# NV TECH SOLUTIONS – Website

Site vitrine trilingue (Français / English / العربية) – Oran, Algérie.

## Structure
```
index.html        page principale
css/style.css     styles
js/main.js        formulaires, chatbot, menu, animations
js/i18n.js        traductions FR / EN / AR (+ RTL)
images/           logo, galerie, références
images/products/  instrumentation & automatisme
video/intro.mp4   vidéo de présentation
```

## Mettre en ligne sur GitHub Pages
1. Créez un dépôt sur GitHub puis envoyez tout le contenu de ce dossier (index.html à la racine).
2. Settings → Pages → Branch `main` / dossier `/ (root)` → Save.
3. Le site sera disponible sur `https://<utilisateur>.github.io/<depot>/`.
